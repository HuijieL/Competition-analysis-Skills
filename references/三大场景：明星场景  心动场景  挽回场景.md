# 三大场景：明星场景 / 心动场景 / 挽回场景

这是典型的“场景营销分层逻辑”，用于匹配 5A 的不同阶段。

------

### 1️⃣ 明星场景（Hero Scenario）

**定义：**
品牌主推、最强势的展示场景，用来制造记忆点。

**特征：**

- 高冲击
- 高识别度
- 强差异化

**例子（消费电子）：**

- 夜拍效果对比图
- 游戏满帧运行
- 三防跌落测试

👉 作用阶段：Aware + Appeal
👉 本质：制造“记住你”的理由

------

### 2️⃣ 心动场景（Trigger Scenario）

**定义：**
触发购买冲动的具体生活化场景。

**特征：**

- 贴近用户真实生活
- 解决具体痛点
- 情绪驱动

**例子：**

- 出差时电池撑一整天
- 运动监测真实心率
- 通勤降噪隔绝地铁噪音

👉 作用阶段：Appeal + Ask
👉 本质：让用户“代入自己”

------

### 3️⃣ 挽回场景（Recovery Scenario）

**定义：**
在用户犹豫或即将流失时的补救设计。

**特征：**

- 解决顾虑
- 降低风险
- 给理由继续购买

**例子：**

- 30天无理由退货
- 分期免息
- 延保
- 价格保护

👉 作用阶段：Ask + Act
👉 本质：消除阻力
