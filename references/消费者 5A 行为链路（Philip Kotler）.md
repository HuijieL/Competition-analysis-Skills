#  消费者 5A 行为链路（Philip Kotler）

Philip Kotler 提出的 **5A 模型** 是数字时代消费者决策路径的升级版本。

### 5A = Aware → Appeal → Ask → Act → Advocate

| 阶段     | 中文理解 | 本质问题       | 在消费电子中的体现            |
| -------- | -------- | -------------- | ----------------------------- |
| Aware    | 认知     | 用户是否知道你 | 看到广告 / KOL测评 / 门店陈列 |
| Appeal   | 吸引     | 是否产生兴趣   | 外观、卖点、价格吸引          |
| Ask      | 搜索     | 是否主动了解   | 看测评、刷评论、对比竞品      |
| Act      | 行动     | 是否购买       | 下单 / 门店成交               |
| Advocate | 传播     | 是否推荐       | 好评、社交媒体分享、复购      |

### 关键理解

- 新模型：强调“Ask”和“Advocate”
- 数字时代用户高度理性 + 社交化

对你GTM非常重要：

- Ask阶段决定“电商评论策略”
- Advocate阶段决定“复购和口碑扩散”
